# セットアップ手順

## 1. スプレッドシートの作成（初回のみ・5分）

1. [Google スプレッドシート](https://sheets.new) で新規スプレッドシートを作成し、名前を「サイネージ管理」にする
2. メニュー「拡張機能 > Apps Script」を開く
3. `gas/setup.gs` の中身をエディタに貼り付けて保存（既存の `function myFunction(){}` は消してOK）
4. 上部の関数選択で `setupAll` を選んで「実行」
5. 初回は権限の承認ダイアログが出る → 自分のアカウントを選び「許可」
6. 「セットアップ完了！」と出たら完了。以下が自動で作られている:
   - 10シート（予定 / 年間予定 / 提出リマインド / 各班の伝達 / シフト・事務募集 / 誕生日 / 新人紹介 / 忘れもの / テロップ / 設定）＋ヘッダー・入力規則・サンプル行
   - Googleドライブに「忘れ物写真」フォルダ（スプレッドシートと同じ場所）

※ `setupAll` は再実行しても既存データを消さない（書式の整え直しのみ）。

## 2. 設定シートの記入

| Key | 入れるもの |
|---|---|
| FLカレンダーID | FL用カレンダーの設定 →「カレンダーの統合」→ カレンダーID をコピー |
| DLカレンダーID | 同上（DL用） |
| 編集許可メール | 書き込みを許可する講師のGmail（カンマ区切り） |

## 3. 忘れ物写真の使い方

1. スマホのGoogleドライブアプリで「忘れ物写真」フォルダを開く
2. 「＋ > アップロード > カメラ」で撮影してアップ
3. 「忘れもの」シートの「写真ファイル名」列にファイル名を書く（例: `水筒.jpg`）

リンクのコピーは不要。サイネージが自動でフォルダから探して表示する。

## 4. サイネージ本体（実装中）

GAS Webアプリとしてデプロイし、モニターPCのブラウザで全画面表示する。手順は実装後に追記。
