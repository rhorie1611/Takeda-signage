# スプレッドシート設計（サイネージ管理）

スプレッドシート1冊「サイネージ管理」に、コーナーごとのシートを持たせる。
講師は該当シートに1行書き足すだけ。GASが定期的に読み取り、サイネージに反映する。

## 共通ルール

- **1行 = 1件**。上の行から順に表示される
- **掲載終了日** を過ぎた行は自動で非表示（行削除は不要。あとから見返せる）
- 空行・先頭が `#` の行は無視
- 日付はすべて `2026/07/12` 形式（シート側で入力規則をかける）

## シート一覧

### 1. 予定（週・月統合）

サイネージ上は「校舎の予定」として1本のリストで表示する。3段階のスタイルで優先度を表現する（説明文などはサイネージ上には出さず、見た目だけで表現）。

- **過ぎた予定（直近7日以内に終わったもの）**: グレーで薄く表示。それより前の古い予定は表示から外れる
- **直近7日間の予定**: 太字で強調表示
- **それ以降〜今月末（月末が近ければ今日から20日後まで）**: 通常の文字

| 列 | 内容 | 例 | 備考 |
|---|---|---|---|
| A | 日付 | 2026/07/11 | 必須 |
| B | 終了日 | 2026/07/13 | 期間イベントのみ。空欄可 |
| C | 内容 | 全国模試（高3・既卒）集合 8:40 | 必須 |
| D | 強調 | 締切 | 「締切」と書くと赤字表示。空欄可 |

### 2. 年間予定（マスタ）

模試・共通テスト・入試など毎年決まっている予定。最初に入れておけば毎年自動反映。

| 列 | 内容 | 例 | 備考 |
|---|---|---|---|
| A | 月 | 1 | |
| B | 日 | 16 | |
| C | 内容 | 大学入学共通テスト（1日目） | |
| D | 種別 | 共通テスト | 「共通テスト」と書いた行がカウントダウンの対象になる |

※年をまたぐ運用：GASが「次に来るその月日」を計算して予定シートと同様に表示する。

### 3. 提出リマインド

| 列 | 内容 | 例 | 備考 |
|---|---|---|---|
| A | 内容 | 指導報告書（先週分） | 必須 |
| B | 締切日 | 2026/07/09 | 表示は「7/9まで」。当日は「本日中」と赤字になる |
| C | 対象 | 講師 | 講師/生徒。表示上のラベル |
| D | 掲載終了日 | (空欄=締切日の翌日で自動終了) | |

### 4. 校舎からの連絡

校舎全体としての連絡事項と、各班からの連絡事項を1シートにまとめる。区分「全体」は校舎全体の連絡として、それ以外（A班など）は班名チップ付きの各班の連絡として表示を振り分ける。同じパネル内で、それぞれ左に色付きの帯を付けたカード形式（校舎全体=青、各班=紫）に分けて見た目でも区別できるようにしている。

| 列 | 内容 | 例 | 備考 |
|---|---|---|---|
| A | 区分 | 全体 / A班 | 「全体」または空欄は校舎全体の連絡。それ以外は班名チップとして表示 |
| B | 内容 | 台風接近のため明日は開校時間を変更する可能性があります | |
| C | 掲載終了日 | 2026/07/11 | |

### 5. FL・DL募集

FL/DLの空き枠募集（「7/12(日) FL 19:40-20:40 1人」のような縦並びの原稿）に対応したシート。
日付・区分は直前の行と同じなら空欄でOK（自動で引き継ぐ）。原稿をほぼそのまま1行ずつ転記できる。

| 列 | 内容 | 例 | 備考 |
|---|---|---|---|
| A | 日付 | 2026/07/12 | 空欄なら直前の行の日付を引き継ぐ |
| B | 区分 | FL | 空欄なら直前の行の区分を引き継ぐ。FL/DL/日曜日/事務など自由記述（区分ごとに色分け表示） |
| C | 内容 | 19:40-20:40 | 時間帯や作業内容。DLのように複数時間帯があればカンマ区切りで1セルに（例: 13:00-16:00, 20:00-21:00） |
| D | 人数 | 1 | 「1人」を軽く強調表示。空欄なら人数表示なし |

表示は日付ごとに自動でグルーピングされ、区分チップ＋内容が並ぶ（例: `7/12(日)  [FL] 19:40-20:40 1人 ／ 20:45-21:45 2人   [DL] 13:00-16:00, 20:00-21:00`）。表示件数の上限はなく、**過去の日付になった行だけが自動で表示から外れる**ので、書いてある分はそのまま載せてよい。この募集コーナーは情報量が多くなりがちなので、専用の1スライドとして丸ごと表示する。

### 6. 誕生日マスタ

優先度が低めのコーナーのため、専用パネルは持たず**最下部のテロップ**で流れる（お知らせ・今日は何の日と同じ枠をローテーション）。

| 列 | 内容 | 例 | 備考 |
|---|---|---|---|
| A | 名前 | 佐藤先生 | |
| B | 月 | 7 | |
| C | 日 | 11 | 当日±N日（設定シートで指定、初期値: 前後3日）でテロップに表示 |

### 7. 新人紹介

こちらもテロップ表示。

| 列 | 内容 | 例 | 備考 |
|---|---|---|---|
| A | 名前 | 山本先生 | |
| B | 紹介文 | 理系・数学担当。よろしくお願いします | |
| C | 掲載終了日 | 2026/07/31 | |

### 8. 忘れもの

こちらもテロップ表示（品物と場所のみ。写真はテロップでは表示されない）。

| 列 | 内容 | 例 | 備考 |
|---|---|---|---|
| A | 見つかった日 | 2026/07/08 | |
| B | 品物 | 水色の水筒 | |
| C | 見つかった場所 | 2F自習室 | |
| D | 状態 | 保管中 | 保管中/返却済。「返却済」は非表示になる |
| E | 写真ファイル名 | 水筒.jpg | 任意。現状はテロップ表示のため使用していないが、将来的に専用コーナーを復活させる際のために残してある |

### 9. テロップ

最下部の帯。「テロップ」シートの内容に加え、誕生日・新人紹介・忘れもの・今日は何の日を順番に流す。

| 列 | 内容 | 例 | 備考 |
|---|---|---|---|
| A | 内容 | 台風接近のため明日は開校時間変更の可能性 | |
| B | 掲載終了日 | 2026/07/10 | |

### 10. 設定

Key-Value形式。管理者だけが触る。

| Key | 値の例 | 説明 |
|---|---|---|
| FLカレンダーID | xxx@group.calendar.google.com | FL用Googleカレンダー |
| DLカレンダーID | yyy@group.calendar.google.com | DL用Googleカレンダー |
| スライド切替秒数 | 20 | 右2/3のローテーション間隔 |
| データ更新間隔(分) | 5 | サイネージがデータを取り直す間隔 |
| 誕生日表示日数 | 3 | 誕生日の前後何日表示するか |
| 編集許可メール | a@gmail.com, b@gmail.com | 編集者ページにログインできるGoogleアカウント |

## FL/DL（シート入力なし・全自動）

- Googleカレンダーからその日のイベントを取得
- イベント名の `【FL】名前` / 先頭の `※` を除去してパース、複数人はカンマ・読点区切り
- DLカレンダーは終日にわたる長時間ブロックをそのまま時系列表示
- 「済み（薄く）/ NOW（赤枠）」はサイネージ側が現在時刻で判定

## 今日は何の日

365日分の記念日データをコードに同梱（外部APIに依存しない）。日付から自動選択。

## アーキテクチャ（確定分）

- 表示: PC ブラウザ全画面（1920x1080想定）
- デザイン: クリーンホワイト。左1/3固定=本日のDL/FL、右2/3=スライド2枚
  - スライド1: 今週の予定 / 提出リマインド / 各班の伝達 / シフト・事務募集
  - スライド2: 今月のトピック / 誕生日・新人紹介 / 忘れもの
- ヘッダー: 時計・今のDL/FL・共通テストカウントダウン。フッター: テロップ
- 実装: GAS Webアプリ（サイネージ配信 + データJSON API）、データはスプレッドシート、コードは clasp でこのリポジトリ管理
