# Takeda-signage

塾の講師休憩スペース向けデジタルサイネージ。
毎日の情報（FL/DL担当・予定・リマインド等）を自動更新して大型モニターに全画面表示する。

## 構成

- **表示**: PCブラウザ全画面（1920x1080）。GAS Webアプリが配信するHTML
- **データ**: Googleスプレッドシート（自由記述コーナー）＋ Googleカレンダー（FL/DL）
- **実装**: Google Apps Script（clasp でこのリポジトリと同期）

## ドキュメント

- [スプレッドシート設計](docs/spreadsheet-design.md)
- [確定デザインモックアップ](docs/mockup/signage-mockup.html)（ブラウザで開くと動作する）

## 画面レイアウト（確定）

- ヘッダー: 時計・今のDL/FL・共通テストカウントダウン
- 左1/3（固定): 本日のDL/FLタイムライン（済み=薄く、現在=NOW赤枠）＋ 提出リマインド
- 右2/3（スライド2枚ローテーション）
  1. 校舎からの連絡（校舎全体・各班、大きめ表示） / 校舎の予定（直近1週間は通常表示、それ以降〜月末は薄く1本化）
  2. 事務募集（上段: FL/DLの空き枠を表形式で左右に表示、下段: 日曜日募集など「その他の募集」。表示件数の上限なし・過去日のみ自動除外）
- フッター: テロップ（お知らせ・新人紹介・忘れもの・今日は何の日を順番に表示。右→左にフェード切替、表示秒数は設定シートで変更可）
- 誕生日: 画面右上に出るポップアップ通知（スマホ通知風、9秒間表示。出現間隔は設定シートで変更可）
