# スプレッドシート設計（サイネージ管理）

スプレッドシート1冊「サイネージ管理」に、コーナーごとのシートを持たせる。
講師は該当シートに1行書き足すだけ。GASが定期的に読み取り、サイネージに反映する。

## 共通ルール

- **1行 = 1件**。上の行から順に表示される
- **掲載終了日** を過ぎた行は自動で非表示（行削除は不要。あとから見返せる）
- 空行・先頭が `#` の行は無視
- 日付はすべて `2026/07/12` 形式（シート側で入力規則をかける）

## シート一覧

### 1. 予定（週・月共用）

今週の予定・今月のトピックはこの1シートから自動で振り分ける。
今週分 → スライド1「今週の予定」、それ以外の当月分 → スライド2「今月のトピック」。

| 列 | 内容 | 例 | 備考 |
|---|---|---|---|
| A | 日付 | 2026/07/11 | 必須 |
| B | 終了日 | 2026/07/13 | 期間イベントのみ。空欄可 |
| C | 内容 | 全国模試（高3・既卒）集合 8:40 | 必須 |
| D | 強調 | 締切 | 「締切」と書くと赤字表示。空欄可 |

### 2. 年間予定（マスタ）

模試・共通テスト・入試など毎年決まっている予定。最初に入れておけば毎年自動反映。

| 列 | 内容 | 例 | 備考 |
|---|---|---|---|
| A | 月 | 1 | |
| B | 日 | 16 | |
| C | 内容 | 大学入学共通テスト（1日目） | |
| D | 種別 | 共通テスト | 「共通テスト」と書いた行がカウントダウンの対象になる |

※年をまたぐ運用：GASが「次に来るその月日」を計算して予定シートと同様に表示する。

| 列 | 内容 | 例 | 備考 |
|---|---|---|---|
| A | 内容 | 台風接近のため明日は開校時間変更の可能性 | |
| B | 掲載終了日 | 2026/07/10 | |

### 10. 設定

Key-Value形式。管理者だけが触る。

| Key | 値の例 | 説明 |
|---|---|---|
| FLカレンダーID | xxx@group.calendar.google.com | FL用Googleカレンダー |
| DLカレンダーID | yyy@group.calendar.google.com | DL用Googleカレンダー |
| スライド切替秒数 | 20 | 右2/3のローテーション間隔 |
| データ更新間隔(分) | 5 | サイネージがデータを取り直す間隔 |
| 誕生日表示日数 | 3 | 誕生日の前後何日表示するか |
| 編集許可メール | a@gmail.com, b@gmail.com | 編集者ページにログインできるGoogleアカウント |

## FL/DL（シート入力なし・全自動）

- Googleカレンダーからその日のイベントを取得
- イベント名の `【FL】名前` / 先頭の `※` を除去してパース、複数人はカンマ・読点区切り
- DLカレンダーは終日にわたる長時間ブロックをそのまま時系列表示
- 「済み（薄く）/ NOW（赤枠）」はサイネージ側が現在時刻で判定

## 今日は何の日

365日分の記念日データをコードに同梱（外部APIに依存しない）。日付から自動選択。

## アーキテクチャ（確定分）

- 表示: PC ブラウザ全画面（1920x1080想定）
- デザイン: クリーンホワイト。左1/3固定=本日のDL/FL、右2/3=スライド2枚
  - スライド1: 今週の予定 / 提出リマインド / 各班の伝達 / シフト・事務募集
  - スライド2: 今月のトピック / 誕生日・新人紹介 / 忘れもの
- ヘッダー: 時計・今のDL/FL・共通テストカウントダウン。フッター: テロップ
- 実装: GAS Webアプリ（サイネージ配信 + データJSON API）、データはスプレッドシート、コードは clasp でこのリポジトリ管理
