# セットアップ手順

## 1. スプレッドシートの作成（初回のみ・5分）

1. [Google スプレッドシート](https://sheets.new) で新規スプレッドシートを作成し、名前を「サイネージ管理」にする
2. メニュー「拡張機能 > Apps Script」を開く
3. `gas/setup.gs` の中身をエディタに貼り付けて保存（既存の `function myFunction(){}` は消してOK）
4. 上部の関数選択で `setupAll` を選んで「実行」
5. 初回は権限の承認ダイアログが出る → 自分のアカウントを選び「許可」
6. 実行が終わると下部の「実行ログ」に「セットアップ完了！」と出る。以下が自動で作られている:
   - 10シート（予定 / 年間予定 / 提出リマインド / 校舎からの連絡 / FL・DL募集 / 誕生日 / 新人紹介 / 忘れもの / テロップ / 設定）＋ヘッダー・入力規則・サンプル行
   - Googleドライブに「忘れ物写真」フォルダ（スプレッドシートと同じ場所）

※ `setupAll` は**再実行しても既存データを消さない**。ヘッダー行や入力規則を整え直すだけで、すでに書き込んだ内容（各シートのデータ・設定シートの値）はそのまま残る。安心して何度でも実行してOK。

## 2. 設定シートの記入

| Key | 入れるもの |
|---|---|
| FLカレンダーID | FL用カレンダーの設定 →「カレンダーの統合」→ カレンダーID をコピー |
| DLカレンダーID | 同上（DL用） |
| 編集許可メール | 書き込みを許可する講師のGmail（カンマ区切り） |

## 3. 忘れ物写真の使い方

1. スマホのGoogleドライブアプリで「忘れ物写真」フォルダを開く
2. 「＋ > アップロード > カメラ」で撮影してアップ
3. 「忘れもの」シートの「写真ファイル名」列にファイル名を書く（例: `水筒.jpg`）

リンクのコピーは不要。サイネージが自動でフォルダから探して表示する。

## 4. サイネージ本体のデプロイ

スプレッドシートの Apps Script プロジェクト（setup.gs を貼った場所）に、以下の3ファイルを追加する。

| リポジトリのファイル | Apps Script側での作り方 |
|---|---|
| `gas/main.gs` | ファイル追加「スクリプト」→ 名前 `main` → 中身を貼り付け |
| `gas/anniversaries.gs` | ファイル追加「スクリプト」→ 名前 `anniversaries` → 貼り付け |
| `gas/index.html` | ファイル追加「HTML」→ 名前 `index` → 貼り付け |

### デプロイ手順

1. エディタ右上「デプロイ > 新しいデプロイ」
2. 種類の選択（歯車アイコン）→「ウェブアプリ」
3. 設定:
   - **次のユーザーとして実行**: 自分
   - **アクセスできるユーザー**: 「全員」（リンクを知っている人だけが開ける。URLは推測困難な長いランダム文字列）
4. 「デプロイ」→ 表示された **ウェブアプリURL** をコピー
5. モニターPCのブラウザでそのURLを開き、F11で全画面表示

※コードを修正したときは「デプロイ > デプロイを管理 > 編集(鉛筆) > バージョン: 新バージョン > デプロイ」で反映（URLは変わらない）。
※サイネージは毎朝4時に自動リロードするので、前日のコード更新は放っておいても翌朝反映される。

### モニターPC側のおすすめ設定

- Chromeのキオスクモードで起動するとタブやバーが出ない:
  `chrome.exe --kiosk "ウェブアプリURL"`（ショートカットのリンク先に追記）
- OSの電源設定で「スリープしない」「ディスプレイを消さない」にする

## 5. 動作の仕組み（ざっくり）

- 画面は5分ごと（設定シートで変更可）に裏でデータを取り直す → スプシに書けば数分でサイネージに反映
- FL/DLの「済み（薄く）/NOW（赤枠）」、時計、共通テストカウントダウンは画面側でリアルタイム更新
- 右2/3のスライドは設定シートの「スライド切替秒数」でローテーション
- テロップは「テロップ」シートのお知らせ＋「今日は何の日」を12秒ごとに順番に表示
- 「今日は何の日」の内容は `gas/anniversaries.gs` に366日分内蔵。自由に書き換えOK
